Claude 101, Lesson 2: **Your First Conversation with Claude**

Course: Claude 101 (Claude Academy) Goal of these notes: learn Claude from zero and use it in everyday life, explained in simple words.

Source: the lesson page (video summary, text sections, exercise). Analogies and example prompts marked "my own" are mine. The lesson page says the video was published in December 2025 and that its "Use style" menu has since been removed, so the app may look a little different today.

**Learning goals**
Start a new conversation with Claude and find my way around the screen.
Write good prompts using clear, specific words.
Upload files and images so Claude has more to work with.
Use follow-up messages to improve Claude's answers.

**1. The big idea**

Claude is a helper that works with me, not instead of me.

I bring: the context (my situation) and my knowledge.
Claude brings: AI abilities, such as writing, analyzing, and building.

**Analogy** (my own): Claude is like a smart classmate in a group project. It's quick and helpful, but it only knows what I tell it about the project.

**Prompt** = the message I type to Claude. Every conversation starts with one.

2. **The screen**: what's where
Part	                                                What it does (simple)
**Text box** (bottom)	                             Where I type my message
**Sidebar**	                                       Start a new chat, or go back to old ones
**Projects**	                                      A folder for related chats. It remembers background info and my custom instructions, so I don't repeat myself
**Artifacts**	                                      Turns ideas into things I can use or share, like small apps, tools, or documents
**Search and tools menu**    	                     Turn on tools such as web search, or connect sources such as Google Drive. Claude uses them when needed
**Model selector (under the text box)**	           Choose which Claude model to use

3. **How to write a good prompt**

Talk to Claude the way I'd talk to a coworker: natural, short, and conversational. No special code words needed.

The 3-part checklist
Part	                              What to tell Claude	                                                Think of it as
1. **Set the stage**	       My role, my goal, and the background	                             "Who am I and what's going on?"
2. **Define the task**	        What I want Claude to do: write, analyze, build, explain	     "What do I need?"
3. **Specify the rules**	       Style, tone, format, length, examples	                            "How should it look and sound?"

Lesson example (shortened): A marketing lead at a small streaming startup asks for a research report on the independent film streaming market, for an investor pitch.

**Stage**: who they are and why they need it
**Task**: find trends, competitors, and growth chances, using current web research with sources
**Rules**: a report of up to 5 pages, with an executive summary and set sections

Go deeper (from the lesson): this checklist comes from the 4D Framework I already learned (Delegation, Description, Discernment, Diligence). It's the Description skill in action.

Weak vs. strong prompt (my own example)
**Weak**: "Write a message to my landlord."
**Strong**: "I'm a tenant (stage). Write a polite message asking my landlord to fix a leaking tap (task). Keep it under 80 words, friendly but firm, and end by asking for a date (rules)."

4. **Giving Claude more to work with** (context)

Three ways: **uploads, connectors, and custom preferences**.

Files I can upload: PDF, Word (DOCX), CSV, text (TXT), and common images (PNG, JPEG). Claude can read text and things like charts and pictures.

I upload...	I can ask...
A document	"Summarize the key points."
An image	"Describe this" or "What does this chart show?"
A spreadsheet	"What trends do you see?"
Code	"Explain this" or "Find the bug."

The file shows up as an attachment in the chat, and then I write my question about it.

Pro-tip: to apply my preferences to every answer, go to Settings > Account > "Instructions for Claude."

5. **Improving answers**: iterate

Iterate = improve step by step. The first answer is a starting point, not the end.

If the first answer misses the mark, I can:

**Ask a follow-up**: "Explain the second point more" or "Make it shorter."
**Give feedback**: "Good, but too formal. Make it more casual."
**Redirect or restart**: steer Claude back if it drifted, or start a new chat for a fresh start.

Pro tip: click the pencil icon on my message to edit it and send it again, instead of adding a new message.

Analogy (my own): like a haircut. Say "a little shorter on the sides," then "a bit more on top," until it's right.

6. **Choosing a model**

The model name appears under the text box. Clicking it lets me switch (this starts a new chat).

Option       	             What it's for
**Sonnet**	                The recommended default. A good balance of ability and cost
**Opus**	                   The largest model, for hard, multi-step jobs such as financial analysis
**Extended thinking**	      Makes Claude think longer on hard problems. Better analysis, but slower. Leave it off for simple tasks
**Research	Claude**        checks many sources and writes a cited report, taking about 5 to 45 minutes (the lesson says Sonnet can do this)

7. **Personalizing Claude**
**Memory**: Claude saves key facts (my role, preferences, past decisions, working style) so I don't repeat them in new chats. I can review, edit, or delete memories in Settings, and they sync across my devices. Example: telling Claude I work in B2B marketing.
**Skills**: reusable instruction sets that teach Claude how to handle a specific task (my writing style, output formats, processes). Claude uses them automatically when relevant. Lesson 7, "Working with skills," covers this.

8. **Key takeaways**
Claude amplifies my work, but my context and knowledge make the result meaningful.
Write naturally, concisely, and conversationally.
Before prompting, set the stage, define the task, specify the rules.
Uploaded documents are a shortcut that helps Claude understand what I need.
Ongoing back-and-forth beats one-off prompts.

9. **Practice** (the lesson's exercise)
Open a conversation with Claude.
Ask a question or give a task. Use the 3-part checklist if I can.
If I need an idea, browse the use-case gallery on Claude Academy.

The lesson has no separate reflection question.

**Ideas for everyday life** (my own)
"I'm a beginner learning to cook. Give me a simple 3-day dinner plan for one person (task). Use only 5 ingredients per meal and no oven (rules)."
"Here is a photo of my electricity bill. Explain what each line means in simple words." (upload)
"I'm shifting from inside sales to AI security. Make me a 4-week study timetable at 1 hour a day, with simple weekly goals."
"Rewrite this message to sound polite and clear: [paste]" (then iterate: "shorter," "warmer")
Do-it-yourself checklist
Wrote one prompt using stage, task, rules
Uploaded one file or image and asked a question
Asked at least two follow-ups to improve an answer
Tried the pencil icon to edit a message
Looked at where Memory and "Instructions for Claude" are in Settings

**Quick revision**
**Prompt** = my message to Claude. **Iterate** = improve step by step.
**3-part checklist**: Stage (who/background), Task (what), Rules (style/format).
**Uploads**: PDF, DOCX, CSV, TXT, PNG, JPEG.
Follow up, give feedback, or restart if the answer isn't right.
**Sonnet** = default. **Opus** = harder jobs. **Extended thinking** = slower but deeper. **Research** = cited reports.
**Memory** = Claude remembers facts about me. Skills = saved how-to instructions.

**Link to my goals**
**Everyday use**: these habits (clear prompts, uploads, follow-ups) are the base of using Claude daily.
**AI Security** (later): anything I upload becomes part of what Claude reads. That's why what I upload and share matters (Diligence), and why uploaded files are a place where hidden instructions could appear (prompt injection).
