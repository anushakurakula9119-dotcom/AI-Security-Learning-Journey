**Learning goal**

Understand when to use the additional Claude products: **Claude Code, Claude Tag, Claude Design, Claude for Microsoft 365, and Claude in Chrome**.

1. **The big idea**
Claude is an intelligence, and Claude.ai is just one way to work with it.
Specialized tools bring Claude into the places where people already work, each tailored to specific workflows.

**Analogy** (my own): Claude is one smart person. **Claude.ai is their main office**. The other products are their desks in other buildings: your code editor, Slack, a design studio, Word and Excel, and your browser.

3. **Claude Code**

What it is: an agentic coding tool that works in my terminal, IDE, browser, or Slack. It understands my codebase (a project's code), runs commands, and handles development workflows using plain language.

In simple words (my own): a coding helper that can actually do the work in my project, not just suggest code.

**When to use it**:

**Build features from plain-English descriptions**: Claude writes code, runs tests, and creates commits.
**Debug**: paste an error message, and Claude analyzes the codebase and fixes the problem.
Learn an unfamiliar codebase by asking how its parts fit together.
**Automate tedious tasks**: fixing lint errors, resolving merge conflicts, writing release notes.
Work in the terminal alongside my existing IDE and tools.

(Lesson 4 said non-developers can skip this one.)

4. **Claude Tag**

What it is: brings Claude into Slack. I tag Claude in any channel or thread to get help or to bring Slack context into Claude conversations.

**When to use it**:

Draft replies, summarize long threads, or break down complex discussions without leaving Slack.
Prepare for meetings: Claude gathers relevant conversations and shared documents.
Onboard to a new team by reviewing channel history for ongoing projects.
Hand off coding tasks from a bug report or feature discussion. Claude can start a Claude Code session using the surrounding context.
Get quick answers about industry trends, technical concepts, or company information mid-conversation.

5. **Claude Design**

What it is: a dedicated space for turning ideas into working interfaces. I describe what I want in plain language, or start from a sketch or screenshot, and Claude builds an interactive prototype. I refine it through conversation and hand it off to my team.

**When to use it**:

Go from a written brief, sketch, or reference screenshot to a working UI prototype without writing code.
Explore design directions by generating and comparing several variations.
Iterate on layout, copy, or interactions by describing changes instead of editing code.
Make prototypes that use my team's design system, so handoffs match what engineering will build.

7. **Claude in Chrome**

What it is: a browser extension that adds Claude as a sidebar in Google Chrome. It can observe my work and take actions in the browser.

**When to use it**:

Summarize articles, research papers, or web pages while browsing.
Draft email replies or manage my inbox.
Automate repetitive form filling.
Test website features or move through multi-step workflows.
Keep context between tabs and tasks, including pulling context from niche internal tools, CRMs, or dashboards.

**Important safety note** (from the lesson)
Currently in public beta.
Anthropic recommends using it for low-risk tasks on trusted websites.
It asks permission before high-risk actions, such as purchasing or sharing personal data.
Certain website categories, including financial services and adult content, are blocked by default.

**Key takeaways**
Claude is available across development, design, productivity, email, and browsing, not only Claude.ai.
Claude Code suits software development; Claude Tag suits work in Slack.
Claude Design turns ideas and sketches into interactive prototypes.
Claude for Microsoft 365 works in place inside Excel, PowerPoint, Word, and Outlook.
Claude in Chrome is a browsing assistant: use it for low-risk tasks on trusted sites, because it asks permission for high-risk actions.

**Quick revision**
Claude Code = coding in terminal/IDE/browser/Slack.
Claude Tag = Claude inside Slack (tag it in a channel or thread).
Claude Design = ideas or sketches to interactive prototypes.
Claude for Microsoft 365 = Excel, PowerPoint, Word, Outlook sidebars. Outlook = beta, installed separately.
Claude in Chrome = Chrome sidebar, public beta, low-risk tasks on trusted sites, asks permission for risky actions, financial and adult sites blocked by default.
Claude Cowork appears in the table only.

**Link to my goals**
Everyday use: for me, the likely first useful ones are Claude for Microsoft 365 (Word, Excel, Outlook) and Claude in Chrome for summarizing pages, if available on my account.
AI Security (later): this lesson is mostly about Claude taking actions in real places, the Agency idea from AI Fluency.
Claude in Chrome can see pages and act in the browser. A malicious web page could hide instructions to trick it (prompt injection). That is why the lesson says low-risk tasks, trusted websites, permission before high-risk actions, and blocked categories. These are security controls.
Claude in Outlook, Word, Excel, and Tag read emails, documents, and chat, which are untrusted inputs that can carry hidden instructions and sensitive data.
Claude Code can run commands and change files, so approval settings (Lesson 4) matter.
The lesson gives no other security guidance beyond the Chrome note, so these links to security are mine.
